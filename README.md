# Event Hunter

iPhoneのSafariから使う個人用イベント収集ツールです。

## 目的
愛知県を起点に、家族で出かける候補になる大きめのイベントを公式情報から集めます。
小規模イベントを網羅することより、展示会・祭り・グルメ・コンサート・スポーツ・ファミリー向け大型企画などの「出かける候補」を見つけやすくすることを優先します。

## 現在の対象地域
- 愛知県
- 岐阜県
- 三重県（伊勢・鳥羽・志摩などを含む）
- 静岡県（浜松・磐田・掛川・袋井・静岡市・焼津など）

情報源は自治体、観光協会、会場、施設などの公式公開情報を使用します。

## 表示
- 今週末
- 今後30日
- すべて
- 都道府県絞り込み
- ジャンル絞り込み
- おすすめ / 保留
- 情報源の品質警告

## 自動更新
GitHub Actionsで毎日 06:05 / 18:05（Asia/Tokyo）に更新します。
mainへの更新時と手動実行でも更新されます。

## 品質保護
公開前に以下を検査します。

- 必須情報源が突然消えていないか
- 既知の取得範囲より情報が欠けていないか
- 一時的に取得できない情報源は前回の正常データを復元
- 必須項目欠落、日付形式不正、開始日・終了日の逆転
- 重複候補

取得不能と「イベントなし」は同じ扱いにしません。
復元データや取得範囲不足がある場合は、サイト上に警告を表示します。

## 注意
- イベント本文や画像は保存せず、名称・日付・会場・ジャンル・公式リンク等を扱います。
- 公式サイトのHTML構造変更やアクセス制限により、個別情報源の取得処理が修正必要になる場合があります。
